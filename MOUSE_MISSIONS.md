# Mouse missions

Four browser games now include a simplified cyan mouse with orange glasses and a bilingual three-medal mission passport. Different successful actions unlock challenges: returned light echoes, photographed sites, Voyager destinations, or discovered heritage objects. Incorrect answers provide hints without penalties. Medals and discovered event IDs use separate, per-game browser storage keys and do not replace existing saves.

The mouse replaces the playable field rover in Keepers of the Legacy, accompanies Oppy, stands beside the telescope and appears beside Voyager as an imaginary guide. Historical vehicles remain visible. Mouse art is drawn in canvas without external assets. Challenges sit below the game so controls remain unobstructed. Language follows each game's existing language selector.

Open project.godot, enter Stories and select a game. The four HTML games open in the default browser; they are not embedded Godot scenes. The existing native Space Guardians chapter reader remains a separate entry. Previous supplied HTML files remain untouched in Downloads and in the earlier MouseNocturneLibrary output.

The existing game mechanics and save formats are retained. The added educational challenges distinguish simulated collection and lunar dust clouds from actual heritage preservation and lunar conditions. Mouse companions are fictional, not historical mission passengers. No Android device testing has been performed.
