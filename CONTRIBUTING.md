# Contributing

Open an issue describing the learning goal or bug, then propose a focused pull request. Preserve existing upstream notices. Contributions must be original or compatible with the applicable licenses.

Use English identifiers, comments and commit messages. Keep Godot player-facing text in both JSON catalogs with matching English keys. Preserve the supplied browser games' bilingual behavior. Cite primary scientific sources for educational changes and distinguish simulations from observations.

Do not commit secrets, personal saves, editor caches, commercial media or third-party images without documented permission. Test affected gameplay and describe what was actually verified, including any simulated input or untested platform.
