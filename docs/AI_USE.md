# AI assistance disclosure

OpenAI ChatGPT/Codex assisted with source code, debugging, documentation, interface and gameplay implementation, procedural Canvas/SVG illustrations, translation drafts, shaders, rigging automation and synthesized sound implementation. The project creator provided the concept, original mouse model, direction and revisions. OpenAI image generation created the painted laboratory background (`assets/laboratory.png`). A visible disclosure is displayed by the Godot interface; the browser adventures retain their existing illustration disclosures.

The 2D mouse and game illustrations are drawn by AI-assisted code; they are not NASA mission photographs. Real NASA images fetched by the native reader must remain identifiable and credited separately. No generative AI service is required during gameplay. Audio is synthesized locally rather than taken from Golden Record recordings or commercial music.

AI output is not a scientific source. Mission statements should be checked against the linked NASA resources. Disclose this assistance in the official submission form as well as this repository. Any separately exported promotional image or video using generated visuals needs its own visible disclosure; this repository cannot certify those future assets.
