# NASA resources and implementation mapping

This is an educational interpretation, not a telemetry analysis pipeline. The source_links.json inventory records NASA URLs present in the supplied HTML; a link alone does not establish that a dataset was processed.

| Resource | How it informs the project | Limits |
| --- | --- | --- |
| [Human-made artifacts on the Moon](https://www.nasa.gov/wp-content/uploads/static/history/humanartifacts.html) | Lunar equipment and heritage storytelling in Guardianes del Legado | Game locations, rarity and collection are fictional; document real artifacts without disturbing them |
| [Opportunity](https://science.nasa.gov/mission/mer-opportunity/) | Rover history and science context in Oppy | Canvas images are illustrations, not captured NASA photographs |
| [Voyager 1](https://science.nasa.gov/mission/voyager/voyager-1/) | Mission timeline, planetary flybys and exploration narrative | Distances and travel are simplified; no live spacecraft telemetry is ingested |
| [NASA CDDIS lunar laser ranging](https://data.nasa.gov/dataset/cddis-llr-data) | Reference for the light-ranging concept in The Silent Mirror | The game uses example values and distance = speed × round-trip time / 2; it does not ingest CDDIS observation files |
| [NASA Image and Video Library](https://images.nasa.gov/) and [API](https://images-api.nasa.gov/) | The native reader searches mission imagery and displays returned attribution | Network-dependent; image-specific rights still apply |
| [Landing on Mars](https://science.nasa.gov/planetary-science/programs/mars-exploration/mission-timeline/how-we-land-on-mars/) | Context for landers and equipment in the supplied stories | Fictional player movement is not a physical landing simulation |

The four adventures connect hardware to the science it enabled. A hardware item remaining in space does not necessarily mean it is inactive; avoid treating every probe or lunar reflector as nonfunctional. Lunar wind-driven dust storms are fictional game mechanics, and heritage collections are digital records.

Before final submission, compare these resources with the Resources tab of the selected challenge and explicitly identify the qualifying NASA resource and the gameplay content derived from it. The challenge resource list could not be independently retrieved during packaging; this document does not certify global-award eligibility.
